# realty-data-miner

Үндсэн хэрэгжүүлэлт: **Go дээрх Unegui.mn crawler**. [Серверт ажиллуулах заавар](CRAWLER.md).

## Local dashboard

### Chrome / Tampermonkey details collector

**v2 batch:** Collector-ийг Update хийсний дараа нэг Chrome зарын хуудсанд «Бүх дэлгэрэнгүйг эхлүүлэх» дарна. Local queue-ээс нэг нэгээр зар нээж, ердийн дугаар харах үйлдлийг хийж, 15 секундийн завсартай үргэлжлүүлнэ. Дууссан ID-г дахин авахгүй. Түр зогсоох товчтой. Зөвхөн нэг collector tab ажиллуулна; Chrome болон local dashboard асаалттай байх шаардлагатай. CAPTCHA, нэвтрэх/нөхцөлийн цонх, дугаар харагдахгүй эсвэл хуудас нээгдэхгүй үед зогсоно. v1 үед тайлбар хоосон хадгалагдах тохиолдлыг зассан; v1 бүртгэлүүд queue-д дахин боловсруулагдана.

Chrome дээр Tampermonkey суулгасан profile-оос [collector суулгах](http://127.0.0.1:8080/realty-collector.user.js) холбоосыг нээгээд Install дарна. Дараа нь Unegui зарын дэлгэрэнгүй хуудсаа reload хийнэ. Collector нь нээсэн хуудсын тайлбар, үзүүлэлт, ердийн «Дугаар харах» товчоор харагдсан утсыг localhost dashboard-д хадгална. Доод зүүн талын ногоон товч нь хадгалсан төлөвийг харуулна, дарж дахин хадгалж болно.

Нөхцөлийн цонх, CAPTCHA болон нэвтрэх шаардлагыг script зөвшөөрөхгүй. Нэмэлт мэдээлэл `data/details/<id>.json`-д тусдаа хадгалагдах тул background crawler шинэчлэхэд устахгүй. Холболтын токен `data/.collector-token` дотор хадгалагдана; хэрэглэгчийн script нь тэр токентой тул бусдад тараахгүй.

Зарын төрлөөр **Зарах**, **Түрээслэх**, **Бүгд**, **Ангилагдаагүй** гэж шүүнэ. Үнийн медиан болон тархалт сонгосон төрөлд таарна. Ангиллыг эх сайтын зарах/түрээслэх жагсаалтаас баталж хадгална; үнэ эсвэл гарчгаар таахгүй. Хуучин зар шинэ ангиллын crawl-д хараахан таараагүй бол ангилагдаагүй хэвээр байна. Crawl нь 30 минут тутам хоёр ангиллын эхний 3 хуудсыг тус бүр шалгана.

Энэ PC дээр [http://127.0.0.1:8080](http://127.0.0.1:8080) хаягаар ажиллана. Нийт цуглуулсан зар, 24 цагт анх бүртгэгдсэн зар, үнийн тархалт, хайлт, дүүрэг/үнийн шүүлтүүр, эрэмбэ, дэлгэрэнгүй цонх, CSV export болон crawl log-той. Шинэ өгөгдөл хадгалагдахад SSE холболтоор ойролцоогоор 1 секундэд dashboard шинэчлэгдэнэ. Холболт тасарвал автоматаар дахин холбогдож, 15 секунд тутам нөөц шалгалт хийнэ; шинэ crawl эхлүүлэхгүй.

`RealtyDataMiner-Dashboard` Windows scheduled task нь хэрэглэгч нэвтрэхэд dashboard-ийг асаана. Одоогийн өгөгдлийг `data/listings.json`-оос уншина. Dashboard нь зөвхөн энэ PC-ийн localhost дээр нээлттэй.

Өөр орчинд ажиллуулах:

```sh
go run ./cmd/dashboard -data data -logs logs
```

Crawler task `RealtyDataMiner-Crawl` нь 30 минут тутам эхний 3 хуудсыг тусдаа шалгана. Компьютер унтаж эсвэл унтарсан үед ажиллахгүй.

## Docker crawler

```sh
docker compose -f compose.crawler.yml up -d --build
```

Жагсаалтаас гарчиг, үнэ, байршил, зурагны URL цуглуулж, ID-аар давхардалгүй JSON хадгална. Доорх нь өмнө бэлдсэн тусдаа Python API-ийн заавар; crawler болон API одоогоор холбогдоогүй.

Сервер дээр ажиллах үл хөдлөх хөрөнгийн мэдээлэл цуглуулах системийн суурь.

Python стандарт сан ашиглана. HTTP API, SQLite хадгалалт, давхардалгүй импорт болон Docker тохиргоотой. Одоогоор сайт scraping холбогоогүй; эх сурвалжийг сонгосны дараа collector нэмнэ.

## Ажиллуулах

```powershell
cd C:\workspace\ORDO\realty-data-miner
$env:API_TOKEN = "replace-with-a-long-random-secret"
python -m app
```

API: `http://localhost:8000`. `GET /health` нээлттэй. Бусад хүсэлтэд `Authorization: Bearer <API_TOKEN>` шаардлагатай.

## API

- `GET /health` — төлөв
- `GET /listings?limit=100` — сүүлд шинэчлэгдсэн зарууд (дээд хязгаар 1000)
- `POST /listings` — зарын JSON массив импортлох; ижил `source` + `external_id` байвал шинэчилнэ

Зарын жишээ:

```json
[
  {
    "source": "example",
    "external_id": "123",
    "title": "2 өрөө байр",
    "url": "https://example.com/listings/123",
    "price": 250000000,
    "currency": "MNT",
    "area_m2": 55,
    "location": "Улаанбаатар"
  }
]
```

Заавал байх талбарууд: `source`, `external_id`, `title`, `url`. Бусад талбарыг эх JSON-д хадгална. Мөнгөний нэгж, байршлын нарийвчилсан загварыг эх сурвалжтай хамт тодорхойлно.

## Docker

`.env.example`-ийг `.env` болгож хуулан токеноо тохируулна.

```sh
docker compose up -d --build
```

Порт зөвхөн localhost дээр нээгдэнэ. Гаднаас хандахдаа HTTPS reverse proxy ашиглана. SQLite өгөгдөл `miner-data` volume-д хадгалагдана; нөөцлөх шаардлагатай.

## Дараагийн ажил

Эх сурвалжийн collector, давтамжит ажиллуулах хуваарь, retry/rate limit, үнийн түүх болон хайлтын шүүлтүүрийг бодит шаардлагаар нэмнэ.

### Collector v2.3 хурд

v2.4 нь `POST /api/collector/details` хариунаас `saved`, `saved_id`, `next` даалгаврыг авна. Miner файлыг хадгалж дууссаны дараа дараагийн queue ID-г сонгоно. Collector энэ баталгааг авсны дараа шилжих тул тусдаа next хүсэлт шаардахгүй. Давхар хадгалалт дараагийн зарын сонголтыг буцааж ухраахгүй. Эхний UI даралт hydration-оос болж ажиллахгүй бол харагдаж буй ердийн утасны товчийг хамгийн ихдээ 3 удаа дарна; CAPTCHA болон зөвшөөрлийн цонх дээр зогсоно.

`document-end` дээр эхэлж, зураг/video ачаалж дуусахыг хүлээхгүй. Текст болон утас DOM-д бэлэн болмогц хадгалаад local API амжилттай баталсны дараа дараагийн зар руу шууд шилжинэ. Өмнөх 3.5 секунд болон 15 секундийн тогтмол хүлээлтийг хассан. Хуудас тус бүрийн текст/утсанд timeout хэвээр. Сайтын rate limit, CAPTCHA, хандалтын шаардлагыг тойрохгүй. Tampermonkey Update шаардлагатай.

### Тусдаа хуудаснууд

- `/` — хяналтын самбар, цуглуулалтын статистик
- `/listings` — заруудын хайлт, шүүлтүүр, CSV, дэлгэрэнгүй
- `/activity` — crawler log

URL-ийг шууд нээх, refresh болон browser Back/Forward дэмжинэ. Хуучин `/#listings`, `/#activity` холбоосууд шинэ URL руу шилжинэ.

### Collector v2.5 автомат эхлэлт

Unegui.mn-ийн аль нэг хуудас нээхэд miner-ийн queue-г автоматаар үргэлжлүүлнэ. Нүүр болон жагсаалтын хуудсаас дараагийн дутуу зар руу шилждэг. Олон tab-аас давхар ажиллахыг miner-ийн 90 секундын worker lease-ээр хориглоно, 20 секунд тутам сунгана. Collector tab хаагдвал 90 секундийн дараа өөр tab үргэлжлүүлэх боломжтой. Өөр tab ажиллаж байвал тухайн tab дээр Үргэлжлүүлэх дарж хугацаа дууссаны дараа дахин оролдож болно. Local dashboard асаалттай байх шаардлагатай. Tampermonkey script-ийн match хүрээ бүх www.unegui.mn хуудсанд өргөжсөн.
